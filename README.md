# TaskFlow — Task Management Application

A web application for creating, updating, and tracking tasks, built as an internship project.

## Features
- User authentication & authorization (sign up / log in)
- Full CRUD operations for tasks (create, read, update, delete)
- Real-time status updates (drag-and-drop between To Do / In Progress / Done)
- Responsive design for web and mobile screens
- Search and priority-based filtering

## Tech Stack
- HTML, CSS, JavaScript (vanilla)

## Getting Started
1. Clone this repository
2. Open `index.html` in any browser — no build step or server required
